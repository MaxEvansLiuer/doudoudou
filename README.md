# doudoudou · 拼豆图纸识别

把拼豆图纸的截图（数字版：每格带色号文字 + 底图配色图例）**识别成可编辑、可统计的电子图纸**。
纯前端单文件级实现，零依赖、零构建，双击 `index.html` 就能用。

> 在线版（开启 GitHub Pages 后）：<https://maxevansliuer.github.io/doudoudou/>

## 能做什么

- 上传 / 拖入 / 直接 `Ctrl+V` 粘贴截图（小红书、抖音的图纸截图都行）
- **自动对齐网格**：按标题里的「宽×高」自动找格距与起点；没把握时不会硬套，会切到手动框选
- **手动框选网格**：拖一个矩形，或者点两个对角点，边缘自动吸附到格线
- **按图例反推色号**：把图底部图例（`A20 109` 这种）粘进去 → 自动按颗数把每格分配到位，数量与图例**完全一致**
- 色号统计（数量 / 占比 / 材质）、点色号高亮（其他变暗）
- 选区：连通块 / 同色全选 / **连续点击累加多选** → 一键删除（置空）或一键改色，可撤销
- 画布操作：**空格 + 拖动平移**、滚轮缩放、方向键微调网格
- 导出：识别后的图纸 PNG（带标尺与色号）、用量清单 CSV

## 快速开始

```text
1. 双击 index.html
2. 拖入图纸截图 → 填标题里的 宽 × 高（如 35 × 39）
3. 点「自动对齐」；如果提示没把握 → 点「框选网格」拖一个框（或点两个对角）
4. 把图例粘到「图例对账」→ 点「套用图例」→ 看到全绿就对了
5. 核对/编辑 → 导出图纸 PNG 或清单 CSV
```

## MARD 色卡

内置 **295 色**（标准 221 + 扩展 74）：

| 系列 | 名称 | 数量 | 识别方式 |
|---|---|---|---|
| A–H / M | 标准实色 | 221 | 颜色匹配 |
| P | 珠光 | 23 | ⚠ 人工确认（颜色不可靠） |
| R | 透明果冻 / 半透明 | 28 | ⚠ 人工确认 |
| T | 全透明 | 1 | ⚠ 人工确认 |
| Y | 夜光 | 9 | ⚠ 人工确认 |
| ZG | 光变 | 8 | ⚠ 人工确认 |
| Q | 温变 | 5 | ⚠ 人工确认 |

数据见 `data/mard-palette.json`（每个色号附 3 个来源的 HEX 便于核对），前端用的紧凑版是 `mard-palette.js`。

## 目录

```text
index.html          界面
core.js             核心算法（采样 / 网格检测 / 聚类 / 图例分配，无 DOM 依赖，可用 node 测）
app.js              界面逻辑 / 渲染 / 交互
mard-palette.js     MARD 295 色（window.MARD_PALETTE）
data/               色卡原始数据
docs/spec.md        需求规格（含样例逆向分析、算法设计与验收标准）
_smoketest.js       界面脚本冒烟测试：node _smoketest.js
_realtest.js        真实截图评测：需要自备 testdata/（不入库，见下）
```

`_realtest.js` 依赖 `testdata/meta.json` + 每张图的 `.rgba`（用 Python 从截图转出来的原始像素）。
这些素材是本地测试用的私人截图，**没有**放进仓库。

## 已知限制

1. 自动对齐不是 100%：格子很小（12~15px）+ 有厚分隔线的图可能锁错，用「框选网格」拖一下即可
2. 半透明 / 珠光 / 夜光等特殊材质与标准色只差 ΔE 1~5，**颜色上无法区分**，需人工确认或用图例颗数对上
3. 淡色水印能顶住，压满整格的重水印仍可能带偏几格 → 用「图例对账」看差额、用「清理杂色」清掉零碎块
4. 满格图案（每格都是豆）要注意「空白判定」别调太高，否则浅色豆会被当空白
