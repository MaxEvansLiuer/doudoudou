# doudoudou · 拼豆图纸识别

把拼豆图纸的截图（数字版：每格带色号文字 + 底部配色图例）**识别成可编辑、可统计的电子图纸**。
纯前端、零依赖、零构建，双击 `index.html` 就能用。

> 🌐 在线版：**<https://maxevansliuer.github.io/doudoudou/>**

## 能做什么

- 上传 / 拖入 / 直接 `Ctrl+V` 粘贴截图（小红书、抖音的图纸截图都行）
- **自动对齐网格**：按标题里的「宽×高」自动找格距与起点；没把握时不会硬套，会切到手动框选
- **手动框选网格**：拖一个矩形，或者点两个对角点，边缘自动吸附到格线；改宽高 / 点框选会自动清掉旧网格
- **按图例反推色号**：把底部图例（`A20 109` 这种）粘进去 → 自动按颗数把每格分配到位，数量与图例**完全一致**
- 色号统计（数量 / 占比 / 材质）、点色号高亮（其他变暗）
- 选区：连通块 / 同色全选 / **连续点击累加多选** → 一键删除（置空）或一键改色，可撤销
- 擦除工具：单击即擦、按住连续擦（不用先选中再删）
- 杂色清理：一键清掉零碎小色块；边缘花纹可「裁上 / 裁下 / 裁左 / 裁右」往里收一格
- 画布操作：**空格 + 拖动平移**（像 PS）、滚轮缩放、方向键微调网格
- **图片转像素画**：上传普通照片 → 指定尺寸（如 50×50 / 100×100）→ 自动生成拼豆图纸；可限色数、抖动、调亮度/对比度/饱和、去背景
- 导出：识别后的图纸 PNG（带标尺与色号）、用量清单 CSV

## 界面

三栏工作台（浅色）：

- **左栏 · 6 步**：导入图片 → 图像预处理 → 网格校准 → 颜色与拼豆映射 → 编辑工具 → 导出与生成
- **中栏 · 画布**：撤销 / 重做、选择、缩放、适配窗口、显示网格、对比原图、全屏；左下角缩略图
- **右栏 · 检查器**：图纸预览（拼豆图纸 / 原始图片 双 Tab）、图像信息、颜色面板、拼豆统计
- **顶部命令条**：打开图片 / 自动识别 / 对齐网格 / 生成图纸 / 导出清单
- **深色模式**：右上角月亮/太阳图标 → 跟随系统 / 浅色 / 深色，选择记在 localStorage

> 图纸本身在深色下仍是白纸（和导出的 PNG 一致），只有界面外壳变深。

导入时可选「**图纸截图**」或「**普通照片**」：选照片会自动隐藏网格校准相关参数、把主按钮换成「生成图纸」，
避免出现对当前任务无效的控件。

> 旧版深色界面保留在 `index.legacy.html`，仅供对照，不参与运行。

## 快速开始

```text
1. 双击 index.html（或打开在线版）
2. 拖入图纸截图 → 左栏「网格校准」填 宽 × 高（如 35 × 39）
3. 点「自动识别」；提示没把握 → 点「对齐网格」拖一个框（或点两个对角点）
4. 点「颜色与拼豆映射」右上角「图例对账」→ 把图例粘进去 → 套用 → 看到全绿就对了
5. 核对 / 编辑 → 导出图纸 PNG 或清单 CSV
```

## 拍照转图纸（图片转像素画）

手上有张普通照片/插画，想做成拼豆图纸：

1. 拖入图片（或 `Ctrl+V` 粘贴）
2. 左侧「图片转像素画」里设 **目标尺寸**（`50×50`、`100×100` 一键填；勾「锁比例」按原图等比）
3. 按需调：**色数上限**（如 24，豆子种类少更好买）、**抖动**（无 / 有序 / 误差扩散）、**亮度 / 对比 / 饱和**、**去背景**（纯色底的图勾上更干净）、**裁剪居中**（不勾=拉伸）
4. 点 **生成像素画** → 结果直接进入同一套流程：色簇可改色、选区可删改、统计、导出 PNG/CSV

> 说明：转换只用 **标准 221 色**（珠光/半透明/夜光/光变这类特殊材质从照片里无法可靠反推，不参与自动转换）。

## 画布操作

| 操作 | 效果 |
|---|---|
| 空格 + 拖动 | 平移画布（按住空格光标变抓手） |
| 右键 / 中键拖动 | 平移 |
| 滚轮 | 以鼠标为中心缩放 |
| 方向键（Shift + 方向键 = 5px） | 微调网格 |
| 点格子 | 选中连通块（或「同色全选」） |
| 连续点击 | 累加多选，再点同一块取消；点空白处清空 |
| 「擦除」工具 | 单击即置空，按住可连续擦，一次笔画只记一步撤销 |

## 背景杂色怎么处理

背景花纹 / 水印 / 压缩噪点可能被当成小色块识别出来，三个办法：

1. **粘图例 + 套用图例**（最省事）：颗数严格按图例锁定，多余杂色会被吸收/丢弃
2. **点「色簇」右上角的「清理杂色」**：把所有少于总数 1% 的零碎色块整块置空
3. **手动删**：色簇里点某个颜色 → 图上「同色全选」→「删除(置空)」

若「明明有豆的格子被当成空白」，把左侧「空白判定」滑块往左拉（浅色豆上的色号文字对比度低）。

## MARD 色卡

内置 **295 色**（标准 221 + 扩展 74）：

| 系列 | 名称 | 数量 | 识别方式 |
|---|---|---|---|
| A–H / M | 标准实色 | 221 | 颜色匹配 |
| P | 珠光 | 23 | ⚠ 人工确认（颜色不可靠） |
| R | 透明果冻 / 半透明 | 28 | ⚠ 人工确认 |
| T | 全透明 | 1 | ⚠ 人工确认 |
| Y | 夜光 | 9 | ⚠ 人工确认 |
| ZG | 光变 | 8 | ⚠ 人工确认 |
| Q | 温变 | 5 | ⚠ 人工确认 |

数据见 `data/mard-palette.json`（每个色号附 3 个来源的 HEX 便于核对），前端用的紧凑版是 `mard-palette.js`。

## 已知限制

1. 自动对齐不是 100%：格子很小（12~15px）+ 有厚分隔线的图可能锁错，用「框选网格」拖一下即可
2. 半透明 / 珠光 / 夜光等特殊材质与标准色只差 ΔE 1~5，**颜色上无法区分**，需人工确认或用图例颗数对上
3. 淡色水印能顶住，压满整格的重水印仍可能带偏几格 → 用「图例对账」看差额、用「清理杂色」清掉零碎块
4. 满格图案（每格都是豆）要注意「空白判定」别调太高，否则浅色豆会被当成空白
5. 色号文字 OCR 还没做：目前靠"按图例颗数反推"而不是读字
